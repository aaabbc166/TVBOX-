## 整理规则

这份配置不是随手堆的，每条都过了一遍：

1. **逐个探测**：每条接口请求两次，两次都失败才判为失效（单次超时会误杀，实测中已多次遇到抖动被误判的情况）
2. **只留能用的**：失效的不收录
3. **js 源额外查目标站**：脚本下载得到不等于能搜到东西，会额外解析脚本里请求的真实域名，目标站全挂的源不收录
4. **不含成人内容源**：明确含成人分类的接口一律不收录
5. **不引入 spider.jar**：本配置的站点无需 spider 扩展，避免加载不可审计的闭源二进制
